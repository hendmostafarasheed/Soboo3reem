# دعوة سبوع ريم الشرنوبي — GitHub Pages

موقع دعوة بسيط من صفحتين، جاهز للرفع إلى GitHub Pages.

## المميزات
- الصفحة الأولى بها زر تفاعلي لفتح الصفحة الثانية.
- فلاش أبيض سريع عند الانتقال بين الصفحتين.
- فقاعات متحركة تطير في الخلفية في الصفحتين.
- زر المكان يفتح بحث خرائط Google عن **White Plaza Askar Group**.
- زر تأكيد الحضور يفتح WhatsApp برسالة جاهزة؛ يمكن اختيار جهة الاتصال وإرسال الرسالة.
- زر مشاركة الدعوة يستخدم نافذة المشاركة في الهاتف، أو يتيح نسخ الرابط عند عدم توفرها.
- تصميم متجاوب مع شاشة الهاتف بنسبة 9:16.

## الرفع إلى GitHub
1. أنشئي Repository جديدًا على GitHub.
2. ارفعي **كل محتويات هذا المجلد** إلى جذر المستودع: `index.html`, `page2.html`, `styles.css`, `script.js`, ومجلد `assets`.
3. من **Settings → Pages** اختاري النشر من الفرع `main` والمجلد `/ (root)`.
4. احفظي الإعدادات وانتظري ظهور رابط الموقع.
5. افتحي الرابط من الهاتف واختبري الأزرار.

## ملاحظات مهمة
- زر المشاركة يشارك رابط الموقع المنشور، لذلك يجب نشر الموقع أولًا على GitHub Pages.
- زر تأكيد الحضور يفتح WhatsApp مع نص جاهز، لكنه لا يرسل الرسالة تلقائيًا؛ المستخدم يختار المستلم ويضغط إرسال.
- رابط خرائط Google يبحث عن اسم المكان. إذا كان لديك رابط الموقع الدقيق من Google Maps، استبدلي رابط `href` الخاص بزر `.maps-hotspot` في `page2.html` بالرابط الدقيق.
- لتعديل نص رسالة التأكيد، عدّلي المتغير `message` داخل `script.js`.
